# Trefoil builds

Windows and macOS builds of Trefoil for playtesting. Download them from the
[Releases page](https://github.com/Tumeoust/trefoil-release/releases).

- Windows: download `trefoil-<version>.zip`, unzip, run `Trefoil.exe`.
- macOS: download `trefoil-<version>-macos.zip`, unzip, right-click `Trefoil.app` > Open the first time (the app is ad-hoc signed, so Gatekeeper asks once).

Online play needs everyone on the same version.
